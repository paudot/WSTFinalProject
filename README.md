# Cookie & Co. — WST Final Project

A PHP-based bakery website with full CRUD functionality built for our Web Systems and Technologies course.
This project was built using XAMPP running Apache and MySQL, with phpMyAdmin for managing the database, all on localhost. Since it runs locally, it may not run directly on another machine without setting it up first. The database has been exported from phpMyAdmin as an SQL file and uploaded to this repository for reference.
---

## CRUD Features
Located under the **Lists** tab:
- **Create** — Add a new product with name, category, price, and description
- **Read** — View all products in a table
- **Update** — Edit any existing product's name, category, price, and description
- **Delete** — Remove a product with a confirmation prompt
